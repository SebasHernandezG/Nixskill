# Nixskill v2 revenue pilot, 2026-11-21

This is one synthetic programming case with two matched pairs, run in the preregistered baseline → Nixskill → Nixskill → baseline order. All four workspaces passed the visible tests and the frozen hidden checker. The two candidate task logs show a successful read of `SKILL.md`; the baselines did not load it.

The counts below are from each first Codex Desktop task turn's local JSONL usage record. The separate telemetry flush turns are excluded. Cached input is included in input; output includes reasoning tokens.

| Task turn | Input | Cached input (included) | Output | Total |
| --- | ---: | ---: | ---: | ---: |
| baseline-1 | 149,136 | 136,704 | 2,111 | 151,247 |
| nixskill-1 | 125,291 | 102,016 | 1,675 | 126,966 |
| nixskill-2 | 153,951 | 126,720 | 2,212 | 156,163 |
| baseline-2 | 148,604 | 135,936 | 1,919 | 150,523 |

| Pair | Baseline total | Nixskill total | Change | Quality gate |
| --- | ---: | ---: | ---: | --- |
| 1 | 151,247 | 126,966 | −16.1% | Both pass |
| 2 | 150,523 | 156,163 | +3.7% | Both pass |
| Combined | 301,770 | 283,129 | −6.2% | Both pairs pass |

The pair effects disagree. This result describes only the revenue case; it does **not** establish savings across programming tasks. The transfer holdout and message negative control in [the v2 plan](V2_EXPERIMENT.md) were not run. The telemetry sidecars reported upload success, but the exact v2 usage breakdown has not been independently checked in the Langfuse UI. Local JSONL is therefore the measurement source for this report.

The frozen run manifest, checker, verification output, and modified workspaces were preserved in a local archive before cleanup. The five original test workspaces were temporary and are not part of the repository. This measures task tokens, not subscription billing.
